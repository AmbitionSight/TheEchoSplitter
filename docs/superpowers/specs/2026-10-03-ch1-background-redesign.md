# 第一关背景重设计《石匠像素》设计稿

> 2026-10-03。方向 A（用户选定）：像素砌石统一材质 + B 色彩纪律 + C 光法则。
> 上位文档：`DESIGN.md`《同一块石头》。本稿只管第一关画面层，不动玩法几何。

## 决策

### 1 · 墙——像素砌石生成器
- 照片苔墙（wall/*.webp + drawMossyWall）在第一关退役；ch2/3 不受影响。
- `prerenderStatic` 内新写砌石生成器：石块宽 60–96px 错缝排布，每块明度差 ±10%、上/左受光边、下/右沉影边、深色灰浆缝；少量裂凿变体。
- 种子固定（沿用 23），确定性渲染。
- 墙顶渐暗、墙脚阴影保留，全部引用统一 `WALL_SEAM` 常量（收敛现状 284/300/292–336/340 四处字面量）。
- 白踢脚线（wall_base 精灵）换成生成器自带的石质基座带。

### 2 · 地——大块凿石板
- floor_brick 0.25x 平铺退役。大块石板 150–220px 宽、错缝大阶；每板明度差 + 顶缘受光 + 底缘沉影；偶发裂纹。
- 掉落"音序线"区域（x 334–466、700 附近）不放地面装饰，保持安静，音素石最跳。

### 3 · 苔藓与青光纪律
- 苔藓=去饱和绿（#4e6b52 族），从石块下缘向上 2×2 拜耳抖动生长；井边更茂密。
- 苔藓永远不碰青色。青 #54e0c8 只给"声音在场"：西墙回声物（shelf/plant/cactus）加极淡青苔光晕；门 ᛟ 灯塔照旧是暗海唯一光源。

### 4 · 光法则
- 四组光池挖孔（月窗/火盆/蜡烛/开关）与光源坐标共用常量，消除 ±25px 错位。
- 月窗正下方地板月光池；火焰脚下椭圆光斑；吸顶灯开灯锥形光带。
- 黄昏级色移出静态烘焙：每帧画在角色之后、暗海之前，角色/音素石/火焰同吃一级大气。

### 5 · 暗区透形
- 暗海基体从纯黑改深靛蓝（rgba(7,8,14,.97) → 底色不变、远端加深层微调蓝）。
- 开灯前暗区剪影 alpha 0.05 → ~0.14：帽架、右墙火把、门轮廓可辨认。
- 光潮、潮头青边、灯塔呼吸全部保留。

### 6 · 门重画
- 现状 3.4x 非整数放大（28→95px）废弃；改矢量手绘拱门 + 门扇，贴合仪式座位几何（door.test 锁坐标不锁美术）。
- 矢量道具（井/火盆/开关/灯）保持墨线描边语言；LimeZu 像素家具保留。

## 工程边界
- 只动 `scene.js`（prerenderStatic / makeDarkness / drawOverlay / drawScene 暗区段）+ `art.js` 色板少量；LAYOUT、content JSON、事件机不碰。
- 砌石程序生成：图集失败时墙地不再退化纯色（家具仍需图集）。
- ch2/3 共享的 drawMossyWall 不动。
- 保持烘焙一次架构与 fallback 路径。

## 测试与验收
- 新增：WALL_SEAM 一致性（渲染带高与碰撞下界出自同一常量组）；光池与光源对齐不变式；砌石生成器确定性（同种子同序列）。
- 既有 123 测试全绿；scene.test 的交互圈≥碰撞圈+20 不变式不受影响（不动 LAYOUT）。
- 验收：`?autostart=1` 与 `?beat=light|lit|door-open` 三状态截图，与旧版同机位对比；右区剪影可辨、无纯黑死区；音素石与青光对比度不降。
