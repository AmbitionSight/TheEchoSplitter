## §0 一句话概括

**在一道劈开走廊的峡谷前，你学会它教你的那个词——不是给世界，是装进身体；在断掉的绳下，你把它还给世界。**
循环仍是全游戏唯一那套：**碰 → 拾 → 拼 → 用**。第二章说两遍同一个句式（失败处 → 声音从那里掉出来 → 重组 → 越过去）：第一遍把词装进身体（jump → 能力），第二遍把词接回世界（rope → 绳）。

教学哲学（承 ch1）：音素不是教的，是发现的。本章新增 2 个词、7 个音素；听辨层（听声点 + 干扰音素）已落地，本规格把它补齐到与第一关回声层同级的密度与承载。

## §1 教学铁律（承 ch1，本章补充）

1. 英语只以「声音 + 情境」出现；NPC 只出声不出字；**禁止任何形式的翻译**。
2. 中文只用于系统元提示（hints/序章/结算/设计说明）；不使用麦克风。
3. 反馈只有自然反应；没有评分、没有「错误」字样、没有弹窗；拖错词具 = 目标纹丝不动 + 咕哝。
4. **英文拼写全剧只在揭示卡出现**：第一章 OPEN 一次；本章 JUMP / ROPE 各一次（每词一次）。
5. 禁止 emoji；图标为 Canvas 矢量。
6. 每词都有用；消耗制自给自足；任意合成顺序无死局。
7. **唯一强调色青 `#54e0c8` =「声音在场」**；金/蓝只给音素石；世界层不得出现未登记发光色（本章须修掉绳端 `#7bd88f` 例外）。
8. 材质统一（DESIGN.md）：UI 与世界同一块石头；矢量道具一律 `PAL.ink` 描边；像素家具整倍缩放，**禁非整数放大**（本章须修绳 0.115×/1.3×、窗 0.533×）。
9. 光锚唯一事实源：**一个光源 = 一个坐标 = 烘焙光池 = 动态光晕（2b 另加挖孔）**。
10. 兜底绝不卡死：无 speechSynthesis 按估时继续；fetch 失败用内联副本；拖拽取消幽灵回弹。
11. **（本章新增）纯指针/触屏必须能通关**——与第一关同级；键盘只是其中一种输入。
12. **（本章新增）红叉例外**：2a CHASM 气泡的红叉为**用户指定**，登记为铁律 3 的唯一例外（见 §15 开放问题 ①，待确认）。
